# Amos 臺灣生活 AI 指南

讓 AI 先查有來源的材料，再幫你選一個今天做得到的小步驟。

面向所有想用 AI 整理生活與工作的繁體中文讀者，不限課程學員。大眾發行候選 v0.2.1｜2026-10-11。

**候選 Skill 已完成主檔完整載入與三個示範題的顯式使用核驗；自然觸發、其他帳號和平台仍需自行測試。初次使用先採 PDF＋提示詞。**

## 第一次用，從這裡開始

1. 點開 [繁體 PDF](pdf/高性價比人生指南-繁體中文轉製版-168VIP-AI-v1.0.pdf)，用檔案頁的下載按鈕存下來。也可點專案上方 **Code → Download ZIP**，解壓縮拿到全部檔案。
2. 在可讀 PDF 的 AI 對話中上傳書，再把 [開始用提示詞](prompts/START.txt) 全部複製、貼到同一段對話。
3. 問一件具體事情：「我寫報告一直被 LINE 打斷，但家人和重要客戶不能漏。請先查書，給今天能試的一步，附節號、條目和這版 PDF 的實體頁碼。」

先檢查出處，再試那一步。AI 讀不到正文時，補傳相關頁面或完整條目，不叫它猜。PDF 與提示詞可免費下載，不需要提供 API 金鑰；AI 平台費用、帳號可用功能與讀取容量，以平台當次狀態為準。

## 想安裝 Skill？

[候選 Skill](skills/amos-tw-life-guide-candidate/SKILL.md) 與 [Skill ZIP](downloads/amos-tw-life-guide-candidate-0.2.1-candidate.1.zip) 提供可供審核、安裝的指令檔案，不是執行程式。本版 0.2.1-candidate.1 將三條正文與授權放在主檔，附加資源讀不到時仍可閱讀主檔回答這三類題。

支援獨立 Skills 的平台，依其管理或安裝流程加入完整資料夾。一般聊天介面先用 PDF＋提示詞。把 GitHub 網址、PDF 或 ZIP 貼到對話，不會自動完成帳號安裝。

裝好後，在新對話明確選用 Skill，確認能讀到完整來源、回答三個示範題。詳見 [使用與安裝](docs/使用與安裝.md)。下載成功不等於安裝、啟用或新對話驗證成功。本包未發布到插件目錄，也沒有全平台安裝保證。

## 這版有哪些內容？

- **427 頁 PDF**：eternity4719《高性價比人生指南》的非官方繁體轉製版，34 節、670 條、9 篇附錄，原作快照 e73cb63。做了字形轉換、排版與適用範圍提醒；**未完成全書臺灣制度改寫**。
- **一般對話提示詞**：搭配當次真正讀得到的 PDF，查完整條目、附來源、區分原書與臺灣情境推論。
- **候選 Skill**：只內建通知、行動起步、訂閱三條完整正文，**沒有內建全書**。其他問題仍需要當次可讀的完整來源。

原書法律、醫療、金融、補貼、資格、金額和服務電話有地區與版本限制，不能直接當臺灣規定。緊急狀況先求助，不等查書；個別醫療、法律與投資決策要找合格專業人士。
