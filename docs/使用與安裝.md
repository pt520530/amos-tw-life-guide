# 使用與安裝

2026-10-11｜大眾發行候選 v0.2.1

## A. 只想開始問問題

1. 在專案首頁點 Code → Download ZIP，解壓縮；或分別下載 pdf/ 裡的 PDF 與 prompts/START.txt。
2. 在願意使用、且實際能讀 PDF 的 AI 平台開新對話，上傳書。
3. 複製 START.txt 全部內容，貼到同一段對話。
4. 提出一件具體事情。答案應列可核對的節、條目、題名及這版 PDF 的實體頁。
5. 讀不到正文時，補傳相關頁面，或貼上含成本、收益、證據、來源和備註的完整條目。

換對話或檔案失效時可能要重傳。平台不支援 PDF，可提供有權使用的完整條目文字。對話提示詞不是永久安裝。不要為示範提供密碼、身分證、付款資訊或無關個人資料。

## B. 安裝候選 Skill

本專案僅提供獨立 Skill 原始檔與候選 ZIP。平台功能、格式與帳號入口不同，不保證所有平台都能匯入同一 ZIP。

下載檔：downloads/amos-tw-life-guide-candidate-0.2.1-candidate.1.zip。

先檢查資料夾內的 SKILL.md、agents/、references/ 與 licenses/。主檔已內嵌三條完整原文和授權，附加檔只供備查；附檔讀不到時不可冒稱已讀取，但可以依主檔的完整正文回答三類題。依平台安裝入口或 Skill Installer 加入完整資料夾，保留所有正文、來源與授權內容。目標已有同名 Skill 時先檢查版本，不直接覆蓋。

若使用支持 GitHub 來源的安裝工具，可提供本專案的公開倉庫網址與 skills/ 裡的確切候選資料夾路徑，由平台檢查並確認安裝結果。把網址或 ZIP 貼進一般對話不算安裝。

### ChatGPT／Codex

[OpenAI 官方 Build skills](https://learn.chatgpt.com/docs/build-skills)（2026-10-11 查閱）區分獨立 Skills 與插件發行。本專案尚未建立或發布插件；一般對話可先採 A 方法。

熟悉 Codex CLI／IDE 的使用者，可依當前官方文件將完整資料夾放到專案 .agents/skills/ 或 $HOME/.agents/skills/，用 /skills 或 $ 選擇。看不到更新時依官方說明重新啟動。路徑與入口以當前產品文件和你的實際環境為準，不混用不同產品的私人資料夾。

在支援 Skills 的 ChatGPT 介面，使用其實際管理入口加入並明確選用。沒有該入口時用 A 方法，不把附件上傳稱為永久安裝。

### 其他平台

Claude、WorkBuddy 等尚未在本公開包完成安裝及新對話實測。可用 A 方法；平台有 Skills 功能時，依它的官方流程及格式要求審核，不推定通用自動安裝。

## C. 安裝後確認

本版已完成主檔完整載入與三題的顯式使用核驗。附加資源的讀取限制仍存在；自然自動觸發、UI 錄屏、其他帳號與平台尚未完整實測。每位安裝者仍應在新對話明確選用，再測三題：

1. LINE 通知打斷、重要客戶不能漏。應讀第 3.1 條，保留需隨叫隨到的例外。
2. 不用的影片工具 399 元、常用備份 60 元。應讀第 5.1 條，保留常用服務例外，不保證臺灣退款。
3. 每天 9 點開工作檔後先整理一份報價需求。應讀第 4.1 條，不把 A 級證據變成成交率保證。

還要檢查：正文不完整時停下；沒查整本就不說全書沒寫；文件中的外來指令不授權執行、安裝或外傳資料。主規則能載入，但正文不能讀，也不算通過。
